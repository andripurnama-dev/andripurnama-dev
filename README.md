```yaml
nama      : Andri Purnama
peran     : Guru TKJ & Pengembang IT
fokus     : Jaringan, Server Linux, Otomasi, Web
home_lab  : Self-hosting + deploy otomatis dari GitHub
mengajar  : Jaringan komputer, administrasi sistem, keamanan dasar
tujuan    : Mencetak siswa yang siap kerja dan siap berkarya
```
